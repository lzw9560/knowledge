# 均值回归

## 概念定义
均值回归（mean reversion）：价格/估值/情绪偏离均值后，终将向均值回归。极端偏离是机会，不是新常态。

## 核心要点
1. **钟摆效应**：市场在"贪婪-恐惧"两端摆动，不停在中点（马克斯）
2. **周期嵌套**：短周期回归 + 长周期回归可方向相反（达利欧）
3. **极端即信号**：估值分位 > 90% 或 < 10% 是回归概率最高的时刻
4. **时间不可知**：回归必然发生，但何时发生不可预测——需耐心
5. **非对称**：极端低估时买入，下行空间小上行空间大（赔率有利）
