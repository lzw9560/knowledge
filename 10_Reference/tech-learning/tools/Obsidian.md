
# Obsidian

## 类别
- 本地优先的 Markdown 笔记 / 知识图谱工具
- 与 Notion / Roam 的对比：Obsidian 文件是本地 `.md`，不锁定在云端；图谱视图基于 `wiki link`
- 双向链接 + 反向链接（backlinks）+ 图谱视图三件套

## 核心用途
- **本地 Markdown 文件**：纯文本，无 vendor lock-in
- **双向链接**：`entity` 自动建立关联，反向链接面板显示引用方
- **图谱视图**：可视化文件间引用关系（本 vault 的 H_Reference/meta/MOC 方法论|MOC 方法]] 的可视化呈现）
- **插件生态**：Dataview（SQL 查询笔记）/ Templater（模板）/ Excalidraw（手绘）等
- **YAML frontmatter**：笔记元数据，可被 Dataview 查询

## 在本知识图谱 Vault 中的使用
- 本 Vault 就是 Obsidian Vault（宿主工具）
- 方法论落地：H_Reference/meta/四构件本体方法论|四构件本体]] 通过 `entity` 链接 + YAML `type:` 字段实现
- 跨领域子区导航：[[10_Reference/investing/MOC]] / [[10_Reference/tech-learning/MOC]] / [[10_Reference/reading/MOC]] / [[10_Reference/projects/MOC]] 都是 Obsidian MOC 文件
- 项目追踪：H_Reference/projects/active/知识图谱|knowledge-graph 元项目]] 记录本 vault 本身
