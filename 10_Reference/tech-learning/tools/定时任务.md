# cron

## 类别
- Unix 定时任务调度器
- 与 [[10_Reference/[[tech-learning/tools/GitHub-Actions|GitHub]] [[Actions]] 的 `schedule` 互为同构：本地用 cron，云端用 Actions schedule

## 核心特性
- **crontab 表达式**：`分 时 日 月 周` 五段式
- **用户级 / 系统级**：`crontab -e`（用户）/ `/etc/cron.d/`（系统）
- **非交互**：cron 任务无 tty，需 `PATH` 显式声明
- **日志**：`/var/log/cron`（系统）/ 用户级重定向到文件

## 常用表达式
| 表达式 | 含义 |
|---|---|
| `0 1 * * 1-5` | 工作日凌晨 1 点 |
| `*/5 * * * *` | 每 5 分钟 |
| `0 9,15,21 * * 1-5` | 工作日 9/15/21 点 |
| `0 0 * * 0` | 每周日凌晨 |
