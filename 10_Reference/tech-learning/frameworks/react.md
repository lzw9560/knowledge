# React

## 语言
- [[10_Reference/[[tech-learning/languages/typescript|TypeScript]] / JavaScript
- JSX/TSX 语法扩展

## 类别
- 前端 UI 框架（声明式、组件化）
- 虚拟 DOM diff 渲染

## 核心特性
- 函数组件 + Hooks（useState/useEffect/useMemo/useCallback）
- 单向数据流（props down, events up）
- 生态：React Router / TanStack Query / Zustand / Vite
- 与 Vue 的差异：React 更"函数式"，Vue 更"响应式"

## 在 Vibe-Research 中的使用
- 前端主框架：`frontend/` Vite + React + TypeScript
- 组件层：`frontend/src/components/` 战法卡 / 漏斗 / 状态机呈现
- 数据层：[[10_Reference/investing/specs/archive/m0-foundation/S013-前端数据层|S013]] 前端数据层（TanStack Query）
