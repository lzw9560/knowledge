# 事件驱动架构

## 类别
- 架构模式（解耦生产者与消费者）
- 与同步请求/响应的对比：事件驱动是"fire and forget + 异步处理"

## 核心特性
- 生产者发布事件（event）到 broker / bus / queue
- 消费者订阅事件，独立处理
- 解耦：生产者不关心谁消费、消费者不阻塞生产者
- 典型实现：Redis pub/sub / RabbitMQ / Kafka / 内存 EventBus
