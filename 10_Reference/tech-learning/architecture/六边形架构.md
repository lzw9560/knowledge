# 六边形架构（端口与适配器）

## 类别
- 架构模式（Alistair Cockburn，2005）
- 又名 Ports and Adapters
- 与 [[10_Reference/tech-learning/architecture/清洁架构|清洁架构]] 同族：都强调领域核心独立于外部，但六边形更强调"端口"契约

## 核心特性
- **端口（Port）**：应用对外暴露的接口契约（入站端口 = API，出站端口 = 依赖倒置接口）
- **适配器（Adapter）**：端口的具体实现（HTTP 适配器 / DB 适配器 / 第三方 API 适配器）
- **核心隔离**：应用核心只依赖端口，不依赖具体适配器
- **可替换性**：同一端口可挂多个适配器（如 DB 适配器从 MySQL 换 Postgres，核心不变）

## 与清洁架构的对比
| 维度 | 六边形 | 清洁架构 |
|---|---|---|
| 隐喻 | 同心圆 | 同心圆 + 依赖反转 |
| 接口 | 端口 | 边界接口 |
| 侧重点 | 可替换适配器 | 依赖方向 |
| 实质 | 同源思想 | 同源思想 |
