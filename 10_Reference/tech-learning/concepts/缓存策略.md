# 缓存策略

## 类别
- 性能优化模式（多语言通用）
- 缓存层级：浏览器 → CDN → 网关 → 应用内存 → 分布式缓存（Redis）→ 数据库

## 核心策略
| 策略 | 读路径 | 写路径 | 适用 |
|---|---|---|---|
| Cache-Aside | 先查缓存，miss 查 DB 回填 | 写 DB 后失效缓存 | 通用，读多写少 |
| Read-Through | 缓存层代理读 DB | 同 Cache-Aside | 缓存层抽象完整 |
| Write-Through | 同步写缓存 + DB | 写缓存，缓存同步写 DB | 强一致 |
| Write-Behind | 异步写 DB | 写缓存，异步刷 DB | 高吞吐，可容忍短暂不一致 |

## 缓存问题与对策
- **缓存穿透**（查不存在的 key）：布隆过滤器 / 空值缓存
- **缓存击穿**（热点 key 过期）：互斥锁 / 永不过期 + 异步刷新
- **缓存雪崩**（大量 key 同时过期）：TTL 随机化 / 多级缓存
- **一致性**：先写 DB 后删缓存（Cache-Aside 标准做法），或延迟双删
