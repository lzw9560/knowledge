# 一字竞价选股法（一字竞价）

## 适用天气
晴天（市场情绪活跃，有明确主攻方向时效果最佳；阴天/暴风雨天一字板信号可能失效）

## 核心逻辑

通过集合竞价阶段的一字板数量，快速锁定当日资金主攻方向，再从中选择辨识度最高的个股进行跟随。同时，通过观察旧主线是否回流来决定卖出时机，形成完整的短线操作闭环。

**一句话带走：** 通过竞价信号发现新方向，通过辨识度找到龙头，再通过旧主线的变化判断离场时机——"跟随资金"的三步闭环。

### 三层因子

| 因子编号 | 因子名 | 逻辑 | 量化条件 |
|---------|--------|------|---------|
| F1 | 竞价方向确认 | 某板块一字板 ≥2 且旧主线一字板归零 → 资金切换方向 | 一字板数 ≥2，旧主线一字板数 = 0 |
| F2 | 辨识度选龙头 | 在新方向板块内选历史反复被资金选择的"老面孔" | 板块内历史涨停频次最高的标的 |
| F3 | 旧主线回流卖出 | 旧主线龙头从跌停拉升 + 板块涨停数骤增 → 新方向走弱 | 旧主线涨停数 ≥10 或龙头跌停→涨停 |

## 入场条件

- 集合竞价阶段，某板块出现 **≥2 个一字板**（F1）
- 新方向与旧主线形成明显切换（旧主线一字板归零或大幅减少）
- 板块内存在高辨识度"老面孔"——历史行情中反复被资金选择的标的（F2）
- 目标个股竞价高开 + 量能配合

## 退出参数

- **卖出信号**：旧主线资金回流（F3）——旧主线龙头从跌停拉升，或板块内涨停数骤增
- **止损**：新方向个股跌破竞价开盘价
- **最大持有**：1-2 日（短线博弈）

## 风险点

- 一字板可能存在主力诱多，需结合板块整体一字板数量判断（≥2 个更可靠）
- "辨识度"是主观判断，需对板块历史行情有充分了解，不可机械执行
- 旧主线回流的判断存在滞后性，可能错过最佳卖点
- 短线博弈属性强，不适合大资金或低频交易者
- 市场情绪极度恐慌时（暴风雨天气），一字板信号可能失效

- 参数来源：淘股吧大神分享帖（2025年8月实战复盘）
- 实战案例：2025-08-12 ~ 08-13 算力切换医药（鸿博股份）

```
一字竞价选股法（竞价选方向）
    ↓

    ↓
```

### 与已有战法的关系

- **→ [[10_Reference/investing/strategies/dragon_head|龙头战法]]**："辨识度选龙头"是龙头追踪的竞价版本。dragon_head 用 sector_rank ≤ 3 量化龙头地位；一字竞价用"历史肌肉记忆"定性判断。可串联：竞价选方向 → 龙头战法确认入场。
- **→ [[10_Reference/investing/strategies/first_plate|首板挖掘]]**：一字板是首板的极端形式（竞价即封死）。一字竞价选方向 → first_plate 确认基因得分 ≥40 后入场。
- **→ [[10_Reference/investing/strategies/consecutive_relay|连板接力]]**：一字竞价是连板接力的前置信号。竞价选方向 → 首板确认 → 连板接力。
- **← 逆向触发**：[[10_Reference/investing/strategies/reverse_package|反包]] / [[10_Reference/investing/strategies/break_reseal|炸板回封]] — 旧主线回流时，旧主线龙头可能触发反包/炸板回封战法。
