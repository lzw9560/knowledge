# S098 首板流选股 §44 合规修复（select 不 auto-rank + 确认时间序）

## 摘要

29 测试绿 + 全量 2279 passed + 1 pre-existing 非 S098（medium-small）

## 问题/目标

该缺陷修复针对首板流选股中因 select 操作默认触发自动排名，导致输出结果顺序与原始时间序列不一致，从而违反 §44 合规要求的问题。核心设计决策是将 select 步骤与排序逻辑完全解耦，禁止在选股过程中引入任何自动排名行为，并强制要求结果严格按确认的时间顺序输出。实现上涉及流程引擎中 Select 算子的配置重构、Rank 模块的条件化调用，以及新增的时间序列一致性校验器，确保选股管线全程遵循合规时序。
