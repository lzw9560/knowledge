# S066 策略特定漏斗架构重构

## 问题/目标

单一权重漏斗无法适配多战法，需按策略特定漏斗架构重构，引入天气硬开关、板块周期、日历因子。

## 核心决策

3 套权重漏斗 + 天气硬开关 + 板块周期 + 日历因子 + 前端三页统一。按战法族拆 3 套权重漏斗，天气（market_phase）作硬开关，板块周期 + 日历因子进入漏斗权重，前端三页（选股池/战法/工作流）统一。

## 受影响文件

- `backend/funnel.py`（3 套权重漏斗）
- `backend/weather.py`（天气硬开关）
- `backend/strategies/`（战法族权重）
- 前端三页组件/hooks/因子子页

## 验收标准

- Phase 0-3 主体完成 2026-08-14
- 后端 9 模块 201 测试 + 5 API
- 前端组件/hooks/因子子页 331 测试
- 3 套权重漏斗 + 天气硬开关就位
