# S084 选股池战法解耦（选股池 Tab + 战法 Tab 两级导航 + 因子补全）

## 摘要

两级 tab 导航 + 因子补全（→ S092 三视图）

## 问题/目标

S084 旨在解决当前选股池与战法逻辑深度耦合导致的配置膨胀、操作路径混乱以及因子缺失引发的策略失效问题。核心设计决策是将原有单一视图拆分为选股池 Tab 与战法 Tab 两级导航，并引入因子补全机制，使战法所需指标在选股池中自动映射与补齐，从而实现池子定义与战法规则的彻底解耦。涉及的关键技术包括前端动态 Tab 容器与状态隔离、战法元数据驱动的因子依赖解析，以及负责实时计算与补全的因子调度引擎。
