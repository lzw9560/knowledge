# S068 工作流触发与结算正确性

## 摘要

盘前/盘中/盘后触发点 + 结算时序对齐（S026/S034/S038/S048 衔接）

## 问题/目标

针对 Vibe-Research 项目中工作流引擎在复杂触发条件下频繁出现漏触发与结算金额偏差的问题，本规范通过引入严格的事件溯源与幂等控制机制，确保每次触发与结算操作在分布式环境下仅执行一次且结果精确。核心设计决策是将工作流触发逻辑与结算计算完全解耦，采用基于时间窗口的批量结算模式，并以不可变账本记录所有状态变更，从而杜绝并发更新导致的金额不一致。涉及的关键技术包括基于 Redis 的分布式锁与延迟队列、PostgreSQL 的 SELECT FOR UPDATE 行级锁、以及用于验证结算正确性的双写比对组件。
