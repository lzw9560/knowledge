# S079 打板 P2 仓位闸 + 龙虎榜黑名单（瘦身版）

## 摘要

仓位闸 + 龙虎榜黑名单（不依赖 S070/S081）

## 问题/目标

S079 聚焦打板策略中因仓位失控和龙虎榜异常席位引发的跟风亏损，通过引入 P2 仓位闸与龙虎榜黑名单实现即时阻断。核心设计决策是采用瘦身思路，仅保留与仓位比例闸值和席位黑名单匹配相关的轻量逻辑，不引入复杂因子或持久化状态，从而将计算开销降到最低。该方案涉及的关键组件包括基于动态阈值的 P2 仓位闸门限流器、龙虎榜席位解析与黑名单匹配缓存，以及嵌入策略执行链路的无侵入拦截器。
