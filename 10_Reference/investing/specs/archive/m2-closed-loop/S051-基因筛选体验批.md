# S051 基因筛选体验批

## 摘要

阈值复位 50/60 + sanity 警告 + 分段视图 + 动态文案 + 零样本注记

## 问题/目标

S051 规范旨在解决基因筛选流程中参数探索成本高、反馈迟滞从而阻碍研究效率的问题，通过提供轻量级、可复现的体验批次让研究人员在安全隔离环境中快速验证筛选策略。核心设计决策是将完整数据集进行代表性采样生成体验子集，并封装为预配置的容器化筛选管道，每个体验批均以不可变快照形式管理，使得参数调整与结果对比可追溯。关键技术组件包括基于 Apache Spark 的基因组采样引擎、由 Nextflow 驱动的标准化筛选工作流，以及集成了 Jupyter 和可视化仪表板的交互式分析前端，元数据层通过 PostgreSQL 管理并与 Vibe-Research 的权限体系衔接。
