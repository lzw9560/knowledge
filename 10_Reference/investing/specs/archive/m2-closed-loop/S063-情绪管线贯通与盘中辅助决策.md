# S063 情绪管线贯通与盘中辅助决策

## 摘要

SentimentContext T-1 贯通 + 盘中 4 维评分 + T+1 投影 + 前端多页

## 问题/目标

S063 致力于解决盘中交易场景下情绪因子与量价体系割裂、实时情绪洞察无法持续转化为可执行辅助信号的问题。核心设计决策是构建一条覆盖数据采集、情绪量化、信号产生与终端提示的标准化流式处理管线，并采用“辅助信号告警 + 人工确认执行”的协同模式，而非全自动接管交易。该管线集成了基于大语言模型微调的实时新闻与社交媒体情感分析引擎、流数据总线（如 Apache Kafka）以及低延迟的情绪热度计分与多因子背离检测组件，最终将情绪辅助信号直接叠加至交易终端界面。
