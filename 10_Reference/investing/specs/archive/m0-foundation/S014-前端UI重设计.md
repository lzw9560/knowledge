# S014 前端 UI 重设计（信息架构+交互统一+视觉+AI 对话）

## 摘要

22项→5组+首页下沉+巨型page拆分+三态统一+移动端+echarts 跟主题

## 问题/目标

S014 针对 Vibe-Research 当前前端界面信息层级混乱、交互模式不统一、视觉风格陈旧以及缺乏原生 AI 对话入口的问题，提出一次系统性的 UI 重设计。核心设计决策是采用以研究项目为中心的信息架构，统一所有视图的导航、筛选与操作交互，并建立一套基于设计令牌的视觉体系，同时将 AI 对话作为全局可唤起的侧边栏，与各个研究上下文深度绑定。该规范涉及 React 组件库的全面重构、基于 shadcn/ui 和 Tailwind CSS 的设计系统落地、以及通过 WebSocket 与后端 LLM 服务集成的实时 AI 对话组件。
