# S008 后端数据层迁移

## 问题/目标

后端散落的 `astock`/`gstock`/`market` 数据出口直接返回原始 dict，无契约约束。需迁移到 S007 契约模型，统一数据层门面。

## 核心决策

返模型 + `response_model` + T13 全批次迁 C 组 engines（11 新 S007 模型）+删 `data_provider`。astock 门面化，数据源拆 `data/sources/`，每个 source 单独模块化，engine 层只消费契约模型产出。

## 受影响文件

- `backend/data/sources/*.py`（数据源拆分）
- `backend/engines/*.py`（T13 全批次迁 C 组）
- `backend/astock.py`（门面化）
- 删除 `backend/data_provider.py`

## 验收标准

- 11 个新 S007 模型迁入 C 组 engines
- `data_provider` 删除
- 所有端点走 `response_model`
- 数据源拆 `data/sources/` 就位
