# S017 A股涨跌预测模型栈

## 问题/目标

建立 A 股涨跌预测 ML 栈，在 S006 §1 新合规边界内承担研究性预测职责。需与工作流解耦，输出可解释的概率与分位区间。

## 核心决策

短线×板块起步，LGB+CatBoost+HMM+Conformal 四头解耦。LGB/CatBoost 双树模型集成，HMM 隐状态相位，Conformal 输出分位区间。输出概率 + 分位区间供战法消费，**不**直接给方向建议（合规边界）。

## 受影响文件

- `backend/ml/models/*.py`（LGB / CatBoost / HMM / Conformal 四头）
- `backend/ml/predict.py`（预测入口）
- `backend/ml/features/`（接 [[specs/S018-多源特征工程]] 特征供给）

## 验收标准

- 四头模型栈就位
- 输出概率 + 分位区间
- 与工作流解耦（研究性预测职责）
