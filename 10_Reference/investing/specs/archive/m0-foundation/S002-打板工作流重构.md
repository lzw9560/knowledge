# S002 打板工作流重构 · P1 候选池诊断统一

## 摘要

短线候选池漏斗 + 诊断卡，六类指标口径统一

## 问题/目标

本 spec 解决打板工作流中 P1 候选池缺乏统一诊断标准、分析结果分散且无法复现比对的问题，导致交易员在盘中决策时难以快速定位最优候选标的。核心设计决策是建立一套标准化的候选池诊断流水线，将多源因子信号、流动性与波动率评估、盘口深度快照统一纳入同一评估框架，并以确定性排序规则输出可追溯的诊断结论。关键技术涉及基于 Apache Flink 的实时因子聚合窗口、ClickHouse 快照存储与多维回测查询，以及一套可插拔的评分算子链，用于动态调整各诊断维度的权重并生成可解释的打板建议。
