# S007 契约层

## 问题/目标

补全前后端数据契约缺失层，避免每个端点各自定义散乱结构。建立 Pydantic v2 模型 + 回归基线 + 契约测试骨架，作为 S006 重写纲领的契约基线。

## 核心决策

Pydantic v2 7 模型 + 10 只 code 基线夹具 + 前后端契约骨架，**不动 astock**（astock 迁移由 [[10_Reference/investing/specs/archive/m0-foundation/S008-后端数据层迁移]] 承担）。通过契约模型定义所有端点产出结构，前后端各按契约实现，实现接口与实现解耦。

## 受影响文件

- `backend/models/*.py`（7 个 Pydantic v2 模型）
- `backend/tests/conftest.py`（基线夹具）
- `frontend/` 契约消费骨架
- 对应 [[10_Reference/investing/stocks/index|stocks/]] [[10_Reference/investing/valuations/index|valuations/]] 等实体

## 验收标准

- 7 个 Pydantic v2 模型就位
- 10 只 code 基线夹具（固定样本票回归基线）
- 前后端契约骨架打通
