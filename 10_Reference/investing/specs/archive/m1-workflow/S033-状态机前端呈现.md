# S033 状态机前端呈现（状态徽标+流转按钮+holding 价格采集）

## 摘要

workflow_state 扩列 entry_price/exit_price/strategy（COALESCE）+ 单股端点 + 列表徽标/抽屉状态卡/流转交互（watching 直连、holding/settled 表单），为 S034 SettlementEngine 铺路

## 问题/目标

本规范为交易状态机的前端可视化呈现提供统一设计方案，解决当前持仓生命周期中状态信息分散、操作入口不明确以及 holding 阶段价格数据采集缺失的问题。核心设计决策是将状态机驱动的前端构件抽象为三类可组合组件：状态徽标（StatusBadge）用于单一真实来源的状态标识，流转按钮（TransitionButton）根据当前状态与权限动态渲染可执行动作，以及 holding 价格采集面板（HoldingPriceCollector）在持仓确认后实时捕获并提交成交价格。关键实现涉及 XState 状态机与 React 组件的深度集成、基于角色权限的按钮可见性控制，以及通过 WebSocket 推送的市场数据服务来支撑价格采集的时效性。
