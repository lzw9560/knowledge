# S045 漏斗层得分显示 + 得分排序 + 多选筛选

## 摘要

FunnelLayerCard 得分显示 + 降序排序 + 战法/R3 触发类型多选筛选

## 问题/目标

S045 旨在解决漏斗层分析中关键指标可读性不足、排序逻辑缺失以及筛选维度单一的问题，使用户无法快速定位高价值分层或灵活组合条件进行深度探查。核心设计决策是在现有漏斗图表与表格视图的基础上，统一引入层级得分展示、多维度排序与交叉筛选机制，并确保这些操作状态可在 URL 参数中持久化，便于分享与回溯。关键实现涉及将漏斗得分计算逻辑封装为可复用的数据管道，利用 React 状态管理驱动多选筛选器与排序控件的联动，并通过 ECharts 的自定义渲染将得分映射为视觉元素，同时后端 API 需支持多字段排序与组合筛选查询。
