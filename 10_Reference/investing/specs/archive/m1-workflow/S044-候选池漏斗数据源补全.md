# S044 候选池漏斗数据源补全（北向 + 板块联动 + 龙虎榜游资频次 + 公告类型化）

## 摘要

四源补全 + 板块源 live 修复（push2delay+ut/分页 496/级别归一/TTL 防封）

## 问题/目标

S044 针对候选池因数据源单一导致信号维度不足、无法识别多因子共振机会的问题，设计了数据源补全方案。核心决策是采用面向切面的数据管线架构，将北向资金、板块联动、龙虎榜游资频次和公告类型化四个数据源解耦为独立采集与标准化模块，并通过统一时间窗口对齐和事件型索引注入候选池。涉及的关键技术包括基于 Flink 的流批一体数据采集、多源异构数据的 Protobuf 标准化、游资席位频次统计算子、公告自然语言处理分类模型，以及候选池的 Redis 二级索引与事件触发机制。
