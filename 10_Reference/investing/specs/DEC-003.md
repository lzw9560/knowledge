# DEC-003 短线胜率优化 grill 裁决

## 选择

2026-08-11 grill-me 会话，D1-D7 全部裁决通过，落地 `docs/workflows/short-term-win-rate-optimization-workflow.md`（v1.1）。要点：
- D1 weather 相位升级为漏斗硬闸门：先跑"相位×次日收益"证据脚本定闸门强度，不拍脑袋直接硬闸
- D2a 区分 `no_history`/`data_missing` 两类零分因子，不做一刀切完整度闸门
- D3a/b/c 战法回测补归因 + 分层口径 weather 四态 + 止损/止盈参数校准缓做
- D4a 展示层改"校准次日红盘概率+样本量 n"，gene_score 降为内部排序字段
- D5a/b/c 纪律执行率 + half-Kelly 仓位建议接 S042 + 排 P2
- D6a/b ML 栈冻结至 W2-W4 落地 + walk-forward 协议+"必须跑赢 S047 分桶基线"硬门槛
- D7a/b/c/d 三 edge 族架构（动量溢价/事件溢价/均值回归）+ value_funnel 增"波段回归"变体 + 结算加字段 + 试错协议四条

## 理由

- 优化目标是期望值不是胜率；项目自有证据（[[specs/S047-基因分权重回测校准]]，n=5267）显示候选池已有正 edge（+2.17%/61.3%），免费胜率来自"不做坏日子/不选坏票/不做坏出场"，不是找更好的股票。
- 外部证据：ashare-sop-engine 回测（6839 只/119 交易日）报告加 L1 宏观闸门后 D5 超额 +0.02%→+0.53%；vibe-astock 派生情绪指标体系作指标定义参照。
- 用户自诊"短线凭感觉做"→ 新增 W0 行为闭环（交易票根+影子对照）先于一切新能力。

## 被否决方案

1. **因子完整度一刀切闸门**：误杀 no_history 首板目标群，改分类处置（D2a）。
2. **拍脑袋直接硬闸门**（D1）：无相位×收益证据，改证据先行。
3. **动量+回归两管道并行上线**：都无法验证，改串行。
4. **引入 qlib/vectorbt 平台依赖**：重且与本地数据层重叠，只借范式。
