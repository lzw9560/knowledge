## 🏢 成分股

```dataview
TABLE WITHOUT ID
  code AS "代码",
  name AS "名称",
  pe_ttm AS "PE",
  market_cap AS "市值"
FROM "10_Reference/investing/stocks"
WHERE type = "stock" AND industry = this.name
SORT market_cap DESC
LIMIT 20
```
