## 📋 规则定义

- 类型：`校验规则`
- 适用实体：`strategies`
- 严重级：`medium`


## ⚡ 触发条件

ora-3 诊断硬事实 5：12 张战法卡是源仓（`backend/strategies/cards/`）正文逐字拷贝，无漂移检测。源仓 `cards/*.md` 一改，vault 立刻过时，且无任何检测机制（审查脚本不比对源仓）。


## 🔧 执行逻辑

```
对每张战法卡（strategies/*.md，排除 index.md）：
  1. 读取 vault 战法卡 frontmatter 的 source_sha（若未填，先回填一次）
  2. 计算源仓对应文件当前 SHA：
     git -C <Vibe-Research> rev-parse HEAD:backend/strategies/cards/<name>.md
  3. 比对：
     if vault_source_sha == source_current_sha:
       drift: false
     else:
       drift: true
       drift_detail: "源仓已变更（新 SHA: <source>），vault 待同步"
       severity: medium（报告"源已变更，vault 待同步"）
```


## ⚠️ 违反处置

- `action_on_violation`：标记 `drift: true` + `drift_detail`
- 报 medium 级 finding："源已变更，vault 待同步"
- 触发 [[10_Reference/investing/actions/源同步]]（源仓 → vault 增量同步，ora-3 D10 规划，待建）
