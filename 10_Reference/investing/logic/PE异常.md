> **严重级**：high  **适用实体**：stocks
>
> **违反处置**：`标记 data_suspect`

## 📋 规则定义

- 类型：`校验规则`
- 适用实体：`stocks`
- 严重级：`high`


## ⚡ 触发条件

股票实体的 frontmatter `pe_ttm` 字段值为负数（公司亏损，PE 无意义）或异常高（>500，疑似数据错误或特殊股本结构）。


## 🔧 执行逻辑

```
对每个 type = "stock" 的实体：
  if pe_ttm < 0:
    标记 data_suspect: true
    suspect_reason: "PE 为负（公司亏损），PE 指标无意义"
  elif pe_ttm > 500:
    标记 data_suspect: true
    suspect_reason: "PE 异常高（>500），疑似数据错误或需人工复核"
```
