> [!info] ⚙️ 规则
> **规则**：`REPORT-LINK-001`  **类型**：自动化规则
> **严重级**：medium  **适用实体**：reports
>
> **违反处置**：`报告末尾生成"图谱关联"+"待入图谱"段`

## 📋 规则定义

- 类型：`自动化规则`
- 适用实体：`reports`
- 严重级：`medium`


## ⚡ 触发条件

每日报告（盘前/盘中/盘后）生成时触发。扫描报告全文，提取所有 6 位数字代码（如 `600519`、`003040`）。


## 🔧 执行逻辑

```
对每份 daily 报告：
  1. 正则扫描 6 位数字代码（排除日期、百分比等干扰）
  2. 对每个代码：
     if exists("10_Reference/investing/stocks/" + code + ".md"):
       在报告末尾"图谱关联"段加 [[10_Reference/investing/stocks/代码]]
     else:
       在报告末尾"待入图谱"段列出，标注"⚠️ 图谱缺此实体，待灌入"
  3. 生成两个段：
     ## 图谱关联（已链接到图谱实体的代码）
     ## 待入图谱（图谱缺失的代码）
```

代码提取正则（建议）：`\b(00\d{4}|30\d{4}|60\d{4}|68\d{4}|688\d{3})\b`（覆盖沪深主板/创业板/科创板常见前缀，排除日期如 2026-09-04）


## ⚠️ 违反处置

- `action_on_violation`：报告末尾生成"图谱关联"+"待入图谱"段
- "待入图谱"段的代码 = 每日具体的入图任务清单，可直接驱动 [[actions/]] 的 inbox stub 流程
