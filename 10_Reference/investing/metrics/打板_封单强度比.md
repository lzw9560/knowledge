# 打板_封单强度比（封单金额/成交额）

## 定义
封单强度比 = 封单金额 / 成交额（或封单/流通市值）。比值越大，次日 Gap Up 概率越大。幻方/九坤头部私募面试题明确此指标。

## 有效性证据
- 幻方/九坤认可"封单金额比=封单金额/成交额，比值越大次日 Gap Up 概率越大"
- 同花顺涨停揭秘 API 提供 seal_rate(封板成功率 0~1)+seal_amount(封单额)+break_times(炸板次数)+is_again(是否回封)
- 东方财富实战称封单额/成交额骤降比 K 线快半小时以上预示资金撤退
- **§44 状态**：盘中盘口信号非 T-1 选股因子（[[edge-in-intraday-not-selection]]），未测

## 数据源
- hithink `limit_up_pool` 返回 `seal_money/max_seal_money`，但 hithink_src.py:312 wrapper bug 丢弃这些字段（实测楚天龙 seal_money=5.4 亿/max_seal=13 亿已在 API 返回）。修 ~10 行解锁
- 同花顺 ths_limit_up_pool 走 _ths_get 限流

## 三问
- 买什么：封单强的标的优先
- 何时买：封板确认瞬间
- 何时卖：封单额/成交额骤降=资金撤退信号
