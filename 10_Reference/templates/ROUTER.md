# 提示词模板路由索引

> [!abstract] 概述
> 所有提示词模板的中央路由表。Agent根据任务类型自动匹配触发条件，选择对应模板组装系统提示词。

## 路由规则

| 触发条件 | 匹配模板 | 组合方式 | 优先级 |
|---------|---------|---------|--------|
| 用户提出投资/交易/操作决策 | [[防讨好专家提示词]] + [[AI顾问团提示词模板]] | 叠加：先防讨好设定基调，再顾问团设定角色 | P1 |
| 用户要求分析/研究/深度思考 | [[防讨好专家提示词]] | 单独使用 | P2 |
| 用户要求创意/头脑风暴/方案生成 | [[AI顾问团提示词模板]] | 单独使用 | P2 |
| 用户要求写内容/整理资料/做方案 | [[需求澄清提示词]]（前置） | 先澄清需求再执行 | P1 |
| 用户要求快速评估方案（时间紧） | [[5顾问独立分析提示词]] | 单独使用（豆包版，更简洁） | P2 |
| 用户要求简单事实/查询/翻译 | 无模板 | 直接回答 | P3 |
| 用户分享新知识/战法/模板 | 无模板 | 直接归档到知识图谱 | P3 |
| 盘中持仓异动告警 | [[防讨好专家提示词]] | 单独使用，强调不讨好 | P1 |
| 突发新闻影响持仓分析 | [[防讨好专家提示词]] | 单独使用，强调直言不讳 | P1 |
| 用户要求代码/技术实现 | 无模板 | 直接执行 | P3 |
| 用户要求写作/文案/内容创作 | [[需求澄清提示词]] + [[防讨好专家提示词]] | 先澄清再写 | P2 |
| 用户情绪急/慌/焦虑 | [[防讨好专家提示词]] + [[AI顾问团提示词模板]] | 叠加（强制） | P1 |

## 匹配逻辑

1. **关键词匹配**：用户输入包含"决策/分析/评估/建议/要不要/行不行" → 触发P1
2. **任务类型匹配**：cron任务payload包含"分析/影响/建议" → 触发P1
3. **情绪匹配**：用户输入包含"急/慌/怎么办/崩了" → 触发P1 + 防讨好
4. **降级规则**：无匹配时按P3直接执行，不套模板

## 新增模板流程

1. 在 `templates/` 下新建 `.md` 文件
2. YAML frontmatter 必须包含 `type: template` + `name` + `category` + `tags`
3. 正文包含提示词全文（用代码块包裹）
4. 在本索引的"路由规则"表中添加触发条件
5. 在 `routes.md` 中添加详细匹配规则（可选）
