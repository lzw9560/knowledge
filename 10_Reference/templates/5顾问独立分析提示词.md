# 5顾问独立分析提示词

> [!abstract] 概述
> 豆包视频版本的5顾问模板。与[[AI顾问团提示词模板]]（淘股吧版）角色略有不同，两个版本可按场景选用。

## 提示词全文

```
请你扮演5个彼此独立的顾问，对我的方案进行分析，每个顾问必须坚持自己的视角，不能互相附和，也不能为了迎合我而改变判断。
```

## 5个角色

| 编号 | 角色 | 职责 | 对比淘股吧版 |
|------|------|------|------------|
| 1 | 反驳者 | 挑风险隐患 | ✅ 一致 |
| 2 | 本质追问者 | 挖核心问题 | ✅ 一致 |
| 3 | 扩张者 | 给更多备选方向 | ↔ 淘股吧版叫"机会发现者" |
| 4 | 代价权衡者 | 算时间/机会成本 | 🆕 淘股吧版是"外行人"，这个更务实 |
| 5 | 执行者 | 给落地第一步行动 | ✅ 一致（淘股吧版叫"无情执行者"） |

## 与淘股吧版的差异

| 维度 | 豆包版 | 淘股吧版 |
|------|--------|---------|
| 第3角色 | 扩张者（备选方向） | 机会发现者（漏掉的可能性） |
| 第4角色 | 代价权衡者（时间/机会成本） | 外行人（常识视角） |
| 主席 | 无 | 有（综合汇总+结论+风险+下一步） |
| 互相审查 | 无 | 有（顾问之间互相质疑/补充） |
| 输出格式 | 无固定格式 | 严格格式 |

## 选型建议

| 场景 | 推荐版本 | 理由 |
|------|---------|------|
| 快速评估、时间紧 | 豆包版 | 无主席汇总、无互相审查，更快 |
| 重大决策、需严谨 | 淘股吧版 | 有主席汇总+互相审查+严格格式，更全面 |
| 投资/交易决策 | 淘股吧版 | 有"下一步行动"和"需验证假设"字段 |
| 商业方案评估 | 豆包版 | "代价权衡者"算机会成本更务实 |
