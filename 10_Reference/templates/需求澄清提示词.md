# 需求澄清提示词

> [!abstract] 概述
> 在AI执行任务前，强制先识别所有模糊/缺失的需求点，逐条向用户确认，等全部明确再正式输出。解决AI"猜着写、跑偏、来回改"的问题。

## 提示词全文

```
执行我的任务前，请先识别所有模糊、缺失或可能影响结果的需求点，逐条向我确认，等全部明确再正式输出结果。
```

## 使用流程

1. **粘贴提示词** + 你的任务描述
2. AI列出疑问清单（风格/篇幅/重点/受众/格式等）
3. 逐条回答，把细节讲清楚
4. 确认信息没遗漏后，让AI生成

## 设计原理

| 指令 | 解决的问题 |
|------|-----------|
| "识别所有模糊、缺失" | 强制AI做需求分析而非直接猜 |
| "逐条向我确认" | 把模糊变明确，减少返工 |
| "等全部明确再正式输出" | 防止AI边猜边写，写完才发现跑偏 |
