# daily-stock-analysis

## 项目概述
每日股票自动化分析工具。盘后定时跑全市场扫描 + 战法触发 + LLM 解读，输出每日投研简报。

详细实体笔记在投研子区：[[10_Reference/investing/specs/每日股票分析项目|daily-stock-analysis]] [[项目实体]]。
