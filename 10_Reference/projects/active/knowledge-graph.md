# knowledge-graph（元项目）

## 项目概述
本 Obsidian Vault 本身作为一个项目——跨维度个人知识体系。GitHub 私有仓 `lzw9560/knowledge` 同步。这是"用知识图谱管理知识图谱"的元项目：vault 记录所有其他项目，也记录自己。

## 三层架构（PARA + 四构件）
```
00_Active/      ← 活跃层：当前项目、近期决策、沟通记录
10_Reference/   ← 参考层：模板、索引、跨项目知识（含投研知识图谱）
20_Archive/     ← 归档层：已结束项目、周复盘压缩包
```
