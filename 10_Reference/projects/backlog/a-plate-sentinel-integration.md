# a-Plate-Sentinel 纳入图谱

## 项目概述
把 [[10_Reference/projects/active/a-plate-sentinel|a-Plate-Sentinel]] 项目的实体/架构/数据流完整纳入本知识图谱。a-Plate-Sentinel 是板块情绪哨兵，与 Vibe-Research 互补（情绪监控 vs 全栈看板）。

## 纳入范围
- 架构实体：[[10_Reference/tech-learning/tools/docker-compose|Docker Compose]] 多容器拓扑（scrapy + redis + api）
- 数据源实体：a-Plate-Sentinel 用的板块/涨停数据源
- 跨项目链接：板块情绪如何回流 Vibe-Research 的天气判定

## 候选理由
- 投研子区已有 [[10_Reference/investing/specs/a-plate-sentinel-project|a-Plate-Sentinel 项目实体]]，但技术栈/容器拓扑等实体尚在项目追踪子区缺位
- 需补全技术栈链接 + 容器编排笔记
