# daily-stock-analysis 纳入图谱

## 项目概述
把 [[10_Reference/[[projects/active/每日股票分析|daily-stock-]][[analysis]] 项目的实体/数据流/决策链纳入本知识图谱，实现"代码改了 → 图谱自动同步"的闭环。

## 纳入范围
- 数据源实体：daily-stock-analysis 用的行情/财务数据源
- 决策链：每日分析产出的候选/快照如何回流投研
- 跨项目链接：与 [[10_Reference/[[projects/active/Vibe-Research|Vibe-]][[Research]] / [[10_Reference/[[projects/active/TradingAgents|trading-]][[agents]] 的数据共享

## 候选理由
- daily-stock-analysis 已是活跃项目（见 [[10_Reference/[[projects/active/每日股票分析|active/daily-stock-]][[analysis]]），但其图谱实体尚不完整
- 需先建实体笔记 + 数据流图，再纳入跨项目链接
