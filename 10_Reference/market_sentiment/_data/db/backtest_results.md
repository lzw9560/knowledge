## 5. 回测方法说明

### Walk-Forward Analysis (WFA)
- **训练窗口**: 4年（约960个交易日）
- **测试窗口**: 1年（约240个交易日）
- **滚动步长**: 1年
- **窗口数量**: 6个（2019-2024年测试）

### 稳健z-score计算
- 公式: `z = (x - median) / (MAD × 1.4826)`
- MAD = 中位绝对偏差，1.4826 = 正态分布一致性因子
- 截断范围: [-3.0, 3.0]，抗极端值，适合A股肥尾分布

### 仓位映射
| 情绪区间 | 建议仓位 | 操作 |
|----------|----------|------|
| Z > 1.5（极度乐观）| 20-30% | 减仓/防守 |
| 0.5 < Z ≤ 1.5（偏乐观）| 40-60% | 持有/微减 |
| -0.5 ≤ Z ≤ 0.5（中性）| 50-70% | 正常配置 |
| -1.5 ≤ Z < -0.5（偏悲观）| 30-50% | 谨慎/观望 |
| Z < -1.5（极度悲观）| 50-80% | 逆向建仓 |

### 熔断机制
- **Level 1（降权）**: 连续3次方向预测错误 → 仓位×0.6，持续5天
- **Level 2（暂停）**: 连续5次错误 或 当日亏损>3% → 仓位降至10%，持续10天
- **Level 3（冻结）**: 系统性风险事件 → 强制降仓至20%以下（本回测未模拟）
