## 📋 框架概览

### 信号体系（v2.0 改造后）

| 层级 | 名称 | 权重 | 角色 | 核心信号 |
|------|------|------|------|---------|
| L0 | 宏观周期层 | 30% | 战略方向 | 社融/M1-M2/PMI/DR007/CPI-PPI/信贷结构 |
| L1 | 政策与监管层 | 15% | 战略方向 | 政策事件/资本市场制度/监管态度 |
| L2 | 机构动向层 | 20% | 战术时机 | 龙虎榜席位博弈/融资融券/大宗交易/增持回购 |
| L3 | 资金面层 | 20% | 战术时机 | 主力资金/竞价异动/ETF申赎/CDS利差/北向(降权) |
| L4 | 市场情绪层 | 15% | 战术确认 | 涨停池结构/炸板率/连板晋级/成交额/板块轮动 |
| L5 | 衍生品层 | 15% | 领先确认 | PCR/IV/基差/Skew/持仓异动 |
| ~L5~ | ~~舆情热度~~ | ~~0%~~ | ~~已删除~~ | 仅保留极端值反向预警(>3σ触发) |

> **注**：权重合计=30+15+20+20+15+15=115%，因L5衍生品从10%升至15%后需微调。实际运行时各层权重在配置文件中归一化。

### 决策流程（两步三验证）

```
第一步：L0+L1 → 战略方向（多/空/中性，1-3个月）
第二步：L2+L3 → 战术时机（入场/出场，1-5天）
第三步：L4+L5 → 交叉确认（置信度调整，0-3天）
```

交叉验证规则：
- L5 PCR极端 + L4涨停池萎缩 → 强烈看多（恐慌见底）
- L5 IV飙升 + L3北向大幅流出 → 确认下跌
- L5基差收敛 + L2机构调研增加 → 底部信号
- L5 Skew转正 + 舆情极度乐观 → 顶部预警

### 评分模型

- **方法**：稳健 z-score（中位数 + MAD × 1.4826）
- **三维向量**：温度 Z + 变化速率 ΔZ + 信号背离度 D
- **置信区间**：95% CI 输出
- **历史分位数**：0-1 分位报告
- **截断范围**：[-3.0, 3.0]

### 熔断机制

| 级别 | 触发条件 | 动作 | 持续 |
|------|---------|------|------|
| Level 1 | 连续3次方向预测错误 | 信号权重降至60% | 5天 |
| Level 2 | 连续5次错误 或 日亏损>3% | 暂停信号输出 | 10天 |
| Level 3 | 系统性风险(千股跌停) | 框架冻结，强制降仓<20% | 20天 |

### 仓位映射

| Z-Score | 状态 | 仓位范围 | 操作 |
|---------|------|---------|------|
| Z > 1.5 | 极度乐观 | 20-30% | 减仓防守 |
| 0.5 < Z ≤ 1.5 | 偏乐观 | 40-60% | 持有微减 |
| -0.5 ≤ Z ≤ 0.5 | 中性 | 50-70% | 正常配置 |
| -1.5 ≤ Z < -0.5 | 偏悲观 | 30-50% | 谨慎观望 |
| Z < -1.5 | 极度悲观 | 50-80% | 逆向建仓 |

三重护栏：单标的≤25% | 总仓位≤90% | 现金≥10% | 止损-7% | 日亏-3%

### 存储原则

| 数据类型 | 存储 | 理由 |
|---------|------|------|
| 每日情绪报告 | Obsidian md | 决策叙事，需要链接和思考 |
| 情绪评分历史 | Obsidian md + SQLite | md供Dataview查询，SQLite供程序计算 |
| 龙虎榜/涨停池 | SQLite + JSON | 结构化数据，程序读写 |
| 宏观指标 | SQLite | 时序数据，程序计算 |
| 衍生品数据 | SQLite | 结构化数据，程序计算 |
| 回测结果 | SQLite + md摘要 | 数据存DB，结论存md |
