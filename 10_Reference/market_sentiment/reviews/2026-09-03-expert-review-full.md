## 一、量化策略师审查

### 总评
框架方向正确——A股是情绪驱动型市场（散户贡献60%-70%成交量），多信号合成情绪指数有实证支撑。平安证券7信号投票法在2014-2024年月度胜率75%，夏普比1.21。但当前框架仍是"定性框架"，离可实盘的"量化系统"差距明显。

### 1. 权重重新分配（基于实证）

**原方案问题：**
- L1政策信号无法量化为日频信号
- L2"机构调研"不是可量化信号
- L5舆情噪音极大，回测中无法稳定贡献alpha
- 龙虎榜幸存者偏差严重

**改进方案（基于平安证券/华泰证券实证）：**

```
资金面层 45%（原L3 25%+L2部分）
  ├─ 北向资金/CDS利差      12%
  ├─ 两融资金              12%
  ├─ 机构/主力资金          11%
  └─ 公募仓位              10%

价量情绪层 30%（原L4 20%）
  ├─ 换手率/成交量          10%
  ├─ 涨跌停/炸板/连板        10%
  └─ 新高股占比/动量         10%

政策宏观层 15%（原L1 20%降权）
  └─ 央行操作/监管政策

衍生品/情绪预期 10%（新增）
  └─ 隐含波动率/PCR

删除：L5舆情热度（噪音高，清洗成本极高）
```

### 2. 评分模型：三维向量替代0-100线性分

0-100单分数的致命缺陷：
- 无法区分信号背离（北向流入但融资下降，互相抵消）
- 阈值过于刚性（50分和90分是完全不同的市场状态）
- 缺失时间维度（高值3天和高值30天意义天差地别）

**改为三维向量：**

```
情绪状态 = (绝对温度Z, 变化速率ΔZ, 信号背离度D)

绝对温度 Z = (X - μ) / σ        # z-score，自适应不同市场环境
变化速率 ΔZ = Z(t) - Z(t-5)     # 5日变化，区分急涨vs缓升
信号背离度 D = |Z_资金 - Z_价量| / (Z_资金 + Z_价量)
```

| 区间 | 判断 | 建议仓位 |
|------|------|---------|
| Z > 2（历史top 2.3%） | 极端贪婪 | 清仓/做空 |
| Z ∈ [1, 2] | 偏热，关注背离度 | 50-70% |
| Z ∈ [-1, 1] | 中性震荡 | 30-50% |
| Z ∈ [-2, -1] | 偏冷 | 70-100% |
| Z < -2 | 极端恐慌 | 左侧布局 |

### 3. 信号胜率排行

**第一梯队（胜率>60%）：**
- 公募基金股票仓位（平安证券：胜率65%，年化13.5%）
- 融资买入额占比
- 换手率（极端值领先一个月）
- 创一年新高股占比（反向指标！极端上行→未来收益下降）

**第二梯队（胜率50-60%）：**
- 融资余额、机构净买入、北向资金/CDS利差、涨停股占比

**应删除（噪音）：**
- L5舆情/股吧热度、龙虎榜（幸存者偏差）、机构调研（不等于买入）

### 4. 必须新增的信号

1. **公募基金仓位**（最重要，实证胜率65%，当前框架完全缺失）
2. **行业ETF净申购额**（华泰验证：散户资金最佳代理，极端值>2σ是高胜率见顶信号）
3. **CDS利差替代北向资金**（北向日频已停更，华泰证实CDS是更好的外资情绪代理）
4. **沪深300持仓PCR + 隐含波动率**（华泰在A股验证有效）
5. **创一年新高股占比**（反向指标）
6. **市场活力指数**（200日均线以上个股占比，川财证券验证：牛市>90%，熊市<10%）

### 5. 回测设计

- 最少7-10年数据（覆盖完整牛熊+2015股灾+2020疫情+2022熊市）
- **必须前向分析（Walk-Forward）**：训练500日→测试60日→每月步进
- 样本外严格隔离：训练60%/验证20%/测试20%
- 必须加入交易成本（佣金+印花税约0.15%+滑点0.05-0.5%）
- 参数敏感性：±20%扫描，夏普比变化>30% = 过拟合
- 性能衰减：衰减率>0.7 = 严重过拟合

### 6. "过热=见顶"逻辑修正

- 只用**极端值**（top 2.3%）领先市场，不是"任何高位"
- 50分（偏热）≠ 90分（极度贪婪），不能混为一谈
- 买入端增加**右侧确认**：初次到10%不买，**再次回到10%之上**再买
- 卖出端采用**分批退出**：首次触及阈值卖50%，每多1σ再卖5%

## 二、市场情绪分析师审查

### 1. L5舆情数据源评估

**现有来源不够，但直接爬取成本极高。** 建议分两阶段：

**第一阶段（低成本，先跑通）：**
- 财联社电报（已有）— 快讯类，时效性最好
- 东方财富股吧热度（通过hithink-finance间接获取热门股数据）

**第二阶段（后续补充）：**
- 雪球热门讨论（需登录，反爬中等）
- 微博财经热搜（反爬极强，建议用第三方API）
- 新增：**抖音/快手财经内容热度**（2024年后A股散户信息获取主渠道已转移）
- 新增：**百度指数/微信指数**（搜索量是情绪的领先指标，免费可抓）

### 2. 社交媒体情绪分析方法

**三层处理 pipeline：**

```
第一层：关键词提取
  - 维护A股情绪关键词库：如"牛市/熊市/抄底/逃顶/割肉/加仓/满仓/空仓"
  - 按情绪方向分类：看多词(+1) / 看空词(-1) / 中性词(0)
  - 统计每日各方向词频，计算"情绪净分值"

第二层：情感分析
  - 对长文本（>50字）用轻量级情感模型分类
  - 分为：极度看多/偏多/中性/偏空/极度看空 5档
  - 加权汇总为当日情感分（-1到+1）

第三层：热度趋势
  - 计算各平台"讨论量7日移动平均"
  - 讨论量突增（>2倍标准差）= 情绪事件
  - 追踪热度趋势方向：上升/见顶/下降
```

### 3. "散户情绪极端值"量化

| 指标 | 过冷（见底信号） | 中性 | 过热（见顶信号） |
|------|----------------|------|----------------|
| 股吧发帖量 | <近60日均值的30% | ±50% | >均值的300% |
| 情感净分值 | <-0.6（极度悲观） | -0.2~0.2 | >+0.6（极度乐观） |
| 百度指数"股票" | <近30日均值的50% | ±30% | >均值的200% |
| 新开户数（中证登） | 连续2周<前月均值60% | 正常 | >前月均值200% |

**关键经验：散户情绪是反向指标。** 股吧发帖量+情感分值双双极端高位 = 顶部信号，不是底部。

### 4. A股情绪周期规律

A股情绪周期典型特征：

```
一个完整情绪周期通常3-6个月：
  绝望（情绪冰点）→ 怀疑（政策利好但没人信）→ 接受（开始反弹）→ 
  兴奋（趋势确立）→ 狂热（人人炒股）→ 恐慌（见顶暴跌）→ 绝望

情绪指标的领先性：
  - 百度指数/搜索量：领先1-2周
  - 股吧热度/发帖量：领先3-5天
  - 融资余额变化：同步偏滞后1-3天
  - 换手率：同步指标，但极端值有1个月领先性
  - 新开户数：滞后指标，确认趋势
```

### 5. 龙虎榜游资动向的用法

- 游资动向反映短期投机情绪热度，不反映基本面
- 用法：统计**知名游资席位**的活跃度（上榜频率+金额）
  - 游资活跃度持续上升 = 市场投机情绪升温
  - 游资活跃度骤降 = 可能监管收紧或市场风险偏好下降
- **不作为个股买卖信号**，只作为市场情绪温度计

### 6. 板块轮动追踪

推荐使用**"四阶段轮动模型"**：

```
阶段1：金融先行（券商/银行领涨）— 市场见底信号
阶段2：成长接力（科技/新能源）— 趋势确立
阶段3：消费补涨（白酒/医药/消费）— 趋势中段
阶段4：低价股/垃圾股补涨 — 趋势末端，见顶预警

追踪方法：
- 每日统计申万一级行业涨跌幅排名
- 计算各行业5日/20日相对强弱（vs沪深300）
- 当领涨板块从阶段1-2切换到阶段3-4时，提高警惕
```

### 7. 经典情绪指标参考

| 指标 | 来源 | 用法 |
|------|------|------|
| 恐贪指数（Fear & Greed） | CNN/东方财富 | >80贪婪，<20恐慌 |
| A股情绪指数 | 东方财富 | 综合情绪温度计 |
| 新增投资者数量 | 中证登 | 滞后确认指标 |
| 沪深300波动率（类似VIX） | 交易所 | 高波动=恐慌，低波动=麻痹 |
| 融资买入额/A股成交额 | 交易所 | 极端高位=过热 |

### 8. 舆情噪音过滤

- **互动率过滤**：发帖量/互动量比值异常低 = 水军刷量
- **来源多样性检查**：三平台同步度>85% = 可能存在协调性刷量
- **时间分布检测**：正常讨论有午休/夜间低谷，水军24小时均匀发帖
- **账号权重**：注册<30天+发帖>10条/天 = 降权处理
- **Z-score过滤**：单日Z>3的舆情数据降权50%

## 三、金融数据工程师审查

### 1. 数据采集可靠性

| 数据源 | 风险 | 建议 |
|--------|------|------|
| L1监管网站 | 高（页面结构随时变更） | 优先用RSS源，必须爬取用Playwright |
| L2/L3/L4 hithink-finance | 中 | ≤30秒/次，日调用<1000次 |
| L5社交媒体 | 最高 | 初期暂不接入，后期用第三方API |

### 2. 同花顺CLI限速方案

```bash
# 限速规则：
- 单接口≤30秒/次
- 日调用总量<1000次
- 指数退避重试：30s → 2min → 10min → 告警放弃
- 连续3次失败 → 暂停该接口1小时
- 全局文件锁防并发
- 每次调用打日志：timestamp + endpoint + response_code + latency
```

### 3. 实时性延迟分析

端到端延迟估算：
```
CLI内部缓存延迟：15-60秒（不可控）
数据解析：1-3秒
写入存储：0.5-1秒
推送通知：1-2秒
总计：17-66秒
```

**关键解决：触发时间比推送时间早30-60秒**，在整点前30秒采集数据。

### 4. 数据存储：混合架构（核心建议）

**全写Obsidian md不合理**，改为混合架构：

```
数据源 → SQLite（中间层，结构化存储） → 定时导出 → Obsidian（展示层）
```

**SQLite核心表：**
```sql
CREATE TABLE market_snapshot (
    ts INTEGER PRIMARY KEY,
    date TEXT, hour INTEGER,
    total_up INTEGER, total_down INTEGER,
    north_net REAL, limit_up_count INTEGER,
    limit_down_count INTEGER, raw_json TEXT
);

CREATE TABLE capital_flow (ts INTEGER, type TEXT, amount REAL);
CREATE TABLE limit_up_pool (date TEXT, code TEXT, name TEXT, reason TEXT);
CREATE TABLE news_items (ts INTEGER, source TEXT, title TEXT, content TEXT, type TEXT);
CREATE TABLE data_source_log (source TEXT, status TEXT, last_ok INTEGER, fail_streak INTEGER);
```

Obsidian只做展示归档，每天23:00从SQLite批量导出当日摘要。

### 5. 定时任务：双轨制

- **系统launchd（主调度）**：盘中9:30-15:00高频触发，最可靠
- **OpenClaw Heartbeat（辅助）**：健康检查、异常告警
- macOS推荐用launchd替代crontab（更底层、更可靠）

### 6. 数据清洗去重

三级去重：
- Level 1：时间窗口指纹（5分钟内同类型重复跳过）
- Level 2：Jaccard相似度≥0.7合并（同源但措辞不同）
- Level 3：相似度0.5-0.7进入人工确认队列

### 7. 熔断与降级

```
连续失败3次  → 指数退避（30s, 2min, 10min, 30min, 1h）
连续失败10次 → 熔断1小时，期间只读缓存
熔断期间    → 推送报告头部显示 ⚠️ [数据源名] 离线
熔断期间连续2次检查成功 → 半开状态，尝试恢复
```

**核心原则：不因单一数据源失败取消推送。** 宁可带着告警推送不完整数据。

### 8. 容错与备份

- SQLite每日备份到iCloud + 本地
- Obsidian Vault用Git版本控制（已装插件）
- hithink-finance账号备用方案
- MacBook关机 = 全停 → 建议设置launchd的KeepAlive

## 四、风控专家审查

### 1. 反身性风险 ⚠️高

"过热=见顶"有严重反身性问题。2015年情绪持续>70但市场继续涨50%。

**修正：情绪>70需要三重确认：**
- ① 当日情绪>70
- ② 连续2日>65（排除单日脉冲）
- ③ 相对过去20日涨幅>15%（确认趋势）

**情绪<30需要三重确认：**
- ① 当日情绪<30
- ② 沪深300/中证1000同步<5分位
- ③ 融资余额缩量>3%

### 2. 虚假信号识别

**诱多模式：**
| 模式 | 识别方法 |
|------|---------|
| 涨停拉板（炸板率<10%） | 炸板率太低反而警惕——主力锁筹非真买盘 |
| 北向尾盘突增 | 查是否MSCI被动配置 |
| 龙虎榜对倒 | 买卖席位重叠>40% = 疑似对倒 |
| 舆情刷屏 | 互动率低 = 水军 |

**诱空模式：**
| 模式 | 识别方法 |
|------|---------|
| 打压制造恐慌 | 跌停集中在一两个板块 vs 系统性恐慌 |
| 融资骤降 | 区分主动还券vs被动强平 |
| 机构假出货 | 查大宗交易是否折价买入 |

**过滤器：**
- Z-score>3降权50%
- 量价背离警报（资金流入但指数收阴 = 疑似假流入）
- 同层至少2个指标同向才采信

### 3. 政策解读风险

- L1得分 = 政策力度分 × 解读一致性系数
- 不自己解读政策，用市场第一天反应倒推
- 政策窗口期（两会/政治局会议前后3日）暂停情绪评分的过热减仓信号

### 4. 龙虎榜陷阱

- 对倒识别：买卖席位重叠>40%标记疑似对倒
- 机构假买真卖：大宗折价买入+二级市场卖出
- L2拆分：L2a真实机构动向(15%) + L2b游资动向(10%)

### 5. 北向资金 ⚠️紧急

- 2023年后信号质量严重下降，相关系数从0.62降至0.38
- 量化外资占比30-40%，日间漂移极强
- 修正：5日滚动净买入、叠加南向对冲检验、权重从30%降至15-20%

### 6. 熔断机制（严重缺失，必须补上）

| 级别 | 触发条件 | 响应 |
|------|---------|------|
| 一级 | 连续3次误判 | 信号权重降至60% |
| 二级 | 连续5次误判或单日亏损>3% | 暂停自动推送，仅手动查看 |
| 三级 | 大盘连续2日跌>3% | 完全冻结，人工审查后解除 |

### 7. 仓位映射表

| 情绪区间 | 建议仓位 |
|---------|---------|
| <25 | 80-95%（重仓抄底） |
| 25-35 | 60-80% |
| 35-50 | 40-60% |
| 50-65 | 25-40% |
| 65-75 | 10-25% |
| 75-85 | 0-10% |
| >85 | 0-5% |

**三重护栏：**
1. 信号确认约束（多维度共振才操作）
2. 时间衰减约束（同档持续5日→仓位下移一档）
3. 波动率约束（沪深300年化波动率>30% → 仓位上限×0.7）

### 8. 合规

- 个人投研使用 ✅合规
- 公开发布预测 ❌高风险（无牌照可能违反《证券投资顾问业务暂行规定》）
- 只发布方法论/数据展示，不做方向性判断

## 五、知识管理专家审查

### 1. 存储方案：md vs 数据库

**结论：不能全存md，混合方案：**

| 数据类型 | 存储方式 | 原因 |
|---------|---------|------|
| 每日情绪报告 | Obsidian md | 人可读，需要review |
| 情绪评分历史 | SQLite + md摘要 | 需要时序查询和图表 |
| 龙虎榜/涨停池原始数据 | SQLite only | 结构化，不需要人读 |
| 政策文件摘要 | Obsidian md | 需要关联和标签 |
| 回测数据 | SQLite + CSV导出 | 大量数值计算 |
| 异动监控记录 | SQLite + 告警md | 实时性要求高 |

### 2. 目录结构设计

```
10_Reference/market_sentiment/
├── daily/                    # 每日情绪报告
```

### 6. 归档策略

- 每日报告：30天后移至 `20_Archive/market_sentiment/daily/`
- 周报：90天后移至归档层
- SQLite数据：永久保留，不归档（体积小）
- 归档时合并同一周的5份日报为1份周报，减少文件数

### 7. 与quant-limit-up项目关联

- 共用SQLite数据库（sentiment.db），两个项目独立但数据互通
- 情绪评分作为quant-limit-up的输入特征之一
- 涨停池数据两个项目共用，quant-limit-up做交易策略，情绪框架做宏观判断

### 8. 标签体系设计

```
一级标签（必打）：
  #market-sentiment  — 所有情绪报告
  #signal            — 信号事件
  #backtest          — 回测

二级标签（按内容）：
  #policy / #institution / #capital / #emotion / #derivative

三级标签（按状态）：
  #overheated / #neutral / #panicked / #turning-point

示例：#market-sentiment #capital #overheated
```

### 9. 每周复盘重点

- 情绪指数预测准确率：预判方向 vs 实际涨跌，统计胜率
- 信号贡献度分析：哪一层信号贡献了最多的正确判断
- 误判复盘：每次误判的原因记录（政策干扰/外资异常/噪音信号）
- 情绪周期定位：当前处于周期的哪个阶段
- 仓位回顾：实际仓位 vs 建议仓位，偏离原因

### 10. 避免信息过载

- 盘中每小时报告只推异动摘要（3-5行），不推全量报告
- 日终summary合并当日所有报告为一份
- 30天归档时合并周报告
- Dataview仪表盘代替逐个文件翻阅
- 只在情绪指数跨越关键阈值时才推送告警
