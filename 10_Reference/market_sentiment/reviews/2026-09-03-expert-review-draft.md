# 大A舆情预判框架 — 专家评审（草稿，等其余3位补齐）

## 角度一：量化策略师（15年A股实战经验）

### 总评
方向对，但仍是"定性框架"，离可实盘的"量化系统"还有明显差距。

### 核心问题
- **权重分配粗糙**：L1政策信号无法量化日频更新，龙虎榜幸存者偏差严重
- **0-100线性分不足用**：无法区分信号背离，阈值过于刚性，缺少时间维度
- **噪音信号太多**：L5舆情/股吧噪音极大，应删除；"机构调研"无法量化

### 权重改进建议（基于平安证券实证）
```
资金面层 45% > 价量情绪层 30% > 政策宏观层 15% > 衍生品/情绪预期 10%
删除 L5 舆情热度
```

### 评分模型改进：三维向量替代0-100线性分
```
情绪状态 = (绝对温度Z, 变化速率ΔZ, 信号背离度D)
绝对温度 Z = (X - μ) / σ  （z-score自适应市场环境）
变化速率 ΔZ = Z(t) - Z(t-5)
信号背离度 D = |Z_资金 - Z_价量| / (Z_资金 + Z_价量)
```

### 信号胜率排行
**第一梯队（胜率>60%）：**
- 公募基金股票仓位（平安证券胜率65%）
- 融资买入额占比
- 换手率
- 创一年新高股占比（反向指标）

**第二梯队（胜率50-60%）：**
- 融资余额
- 机构净买入
- 北向资金/CDS利差

**应删除：**
- L5舆情热度、龙虎榜（幸存者偏差）、机构调研

### 新增关键信号
1. **公募基金仓位**（最重要，缺失严重）
2. **行业ETF净申购额**（华泰验证：散户资金最佳代理）
3. **CDS利差替代北向资金**（北向日频已停更）
4. **沪深300持仓PCR + 隐含波动率**（华泰验证）
5. **创一年新高股占比**（反向指标）
6. **市场活力指数**（200日线上个股占比，川财证券验证）

### "过热=见顶"逻辑修正
- 只用**极端值**领先市场，不是"任何高位"
- 50分（偏热）≠90分（极度贪婪）
- 买入端增加**右侧确认条件**
- 卖出端采用**分批退出**

### 回测设计
- 最少7-10年数据（覆盖完整牛熊）
- 必须前向分析（Walk-Forward）
- 必须含交易成本
- 参数敏感性分析
- 性能衰减分析

### P0改造清单
✓ 删除L5舆情热度
✓ 加入公募仓位、行业ETF净申购额、CDS利差
✓ 0-100绝对分改为z-score
✓ 回测用前向分析+样本外隔离+成本全算

## 角度三：金融数据工程师

### 数据采集可靠性
- L1（监管）：高风险，页面结构随时变更，建议优先RSS/Atom源，必须抓取时用Playwright
- L2/L3/L4（hithink-finance）：中等风险，频率控制在≤30秒/次
- L5（社交媒体）：最高风险，微博/雪球/股吧反爬极强，**建议初期暂不接入**

### 同花顺CLI限速
- 单接口≤30秒/次，日调用<1000次
- 指数退避重试，连续3次失败暂停1小时
- 全局限速：文件锁防并发

### 实时性延迟
- CLI内部15-60秒延迟（不可控）
- 端到端总计17-66秒
- 关键解决：触发时间要比推送时间早30-60秒

### 数据存储：混合架构
```
数据源 → SQLite（中间层） → 定时导出 → Obsidian（展示层）
```
- Obsidian只做展示归档，不做存储
- SQLite单文件，无外部依赖，macOS友好
- 核心表：market_snapshot、capital_flow、limit_up_pool、news_items

### 定时任务：双轨制
- **系统crontab/launchd（主调度）**：盘中高频触发
- **OpenClaw Heartbeat（辅助）**：健康检查、异常告警
- macOS推荐用launchd替代crontab

### 数据清洗去重
- Level 1：时间窗口指纹（5分钟内重复跳过）
- Level 2：Jaccard相似度≥0.7合并
- Level 3：待确认队列人工review

### 熔断机制
- 连续失败3次→指数退避
- 连续失败10次→熔断1小时
- **不因单一数据源失败取消推送**

### 单点故障
- 最高风险：MacBook关机、hithink-finance账号被封
- SQLite单文件损坏→历史数据丢失
- 建议：SQLite备份、Git版本控制、多账号备用

## 角度四：风控专家

### 总评
框架在信号权重分配、情绪评分逻辑、数据源可信度三个层面存在结构性风险。

### 1. 反身性风险 ⚠️高
- "过热=见顶"有严重反身性问题，2015年情绪持续>70但市场继续涨50%
- 修正：情绪>70需要三重确认（连续2日>65 + 20日涨幅>15% + 趋势确认）
- 单一情绪指数不应单独触发交易决策

### 2. 虚假信号识别 ⚠️高
**诱多模式：** 涨停拉板（炸板率太低反而警惕）、北向尾盘突增（查是否被动配置）、龙虎榜对倒（买卖席位重叠>40%）、舆情刷屏（互动率低=水军）
**诱空模式：** 打压制造恐慌、融资余额骤降（区分主动还券vs被动强平）、机构假出货
**过滤器：** Z-score>3降权50%、量价背离警报、来源多样性检查

### 3. 政策解读风险 ⚠️中-高
- 同一政策不同环境解读完全相反
- 修正：L1得分 = 政策力度分 × 解读一致性系数
- 不自己解读政策，用市场反应倒推

### 4. 龙虎榜陷阱 ⚠️高
- 游资对倒：买卖席位重叠>40%标记疑似对倒
- 机构假买真卖：大宗折价买入+二级市场卖出
- 建议L2拆分：L2a真实机构动向(15%) + L2b游资动向(10%)

### 5. 北向资金 ⚠️高（紧急）
- 2023年后信号质量严重下降，相关系数从0.62降至0.38
- 量化外资占比30-40%，日间漂移极强
- 修正：用5日滚动净买入、叠加南向对冲检验、权重从30%降至15-20%

### 6. 过拟合风险 ⚠️中-高
- 分段回测、滚动窗口验证、参数敏感度测试
- 用概率表述替代二元判断
- 建立动态阈值（高波动环境阈值上移）

### 7. 熔断机制（严重缺失）
- 一级：连续误判3次→降权60%
- 二级：连续误判5次或单日损失>3%→暂停推送
- 三级：大盘连续2日跌>3%→完全冻结

### 8. 合规风险 ⚠️中-高
- 个人投研使用✅合规
- 转发他人⚠️灰色地带
- 公开发布预测❌高风险
- 代客理财/收费荐股❌违法

### 9. 风险指标体系
- 信号胜率（20日滚动）<55%黄色，<50%熔断
- 组合最大回撤-5%黄色，-8%减仓50%
- 单日亏损-3%黄色，-5%停止开新仓

### 10. 仓位映射
- 情绪<25→80-95%仓位，25-35→60-80%，35-50→40-60%
- 50-65→25-40%，65-75→10-25%，75-85→0-10%，>85→0-5%
- 三重护栏：信号确认约束 + 时间衰减约束 + 波动率约束

### P0（本周必须）
- 增加熔断机制
- 北向资金降权+过滤
- 仓位与情绪指数映射表
