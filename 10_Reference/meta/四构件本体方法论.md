# 四构件本体方法论

> 领域无关的知识图谱构建方法论。本 vault 的投研子区是这套方法论的实例化。
> 蒸馏自 `nano-ontoprompt` skill（`ontology-knowledge-graph`）。本文件是"方法论 ↔ 实例化"的对照表。

## 四构件定义

| 构件 | 通用定义 | 性质 | 投研实例化 | 当前状态 |
|---|---|---|---|---|
| **1 实体** | 有唯一标识的领域对象（带 frontmatter 结构化字段） | 静态层 | stocks/industries/concepts/strategies/data-sources/specs/... | ⚠️ 5/14 类有内容（ora-3 事实 3） |
| **2 关系** | 实体间的谓词连接（`[[]]` 双链 + frontmatter 谓词标注） | 静态层 | 10 个谓词：belongs_to / tagged / covered_by / has_metric / valued_at / involves / affects / matches / authored_by / triggered_by | ⚠️ 平面，无 kind 维度（ora-3 §3.3 待落地） |
| **3 逻辑规则** | 可机器执行的约束/状态机/推断/自动化规则 | 动态层 | `logic/` — 11 条规则（ora-3 §3.1 已填 6 条实证规则） | ✅ 已填充（Week 1-2 落地） |
| **4 动作** | 状态流转与维护操作（CRUD/状态流转/链接维护/审计快照） | 动态层 | `actions/` — 6 个动作（promote-from-inbox / sync-from-source / auto-link-report / approve-entity / rename-entity） | ✅ 已填充（Week 2 D10 落地） |

## 构件间依赖

```
1 实体 ──被连接──> 2 关系 ──被约束──> 3 逻辑规则 ──触发──> 4 动作
                                          │
                                          └──审计快照──> reviews/
```

**关键原则**：
- 构件 3（逻辑规则）必须**可机器执行**——即 `scripts/vault_audit.py` 里有对应检查函数。规则写完但脚本没实现 = 文档而非规则。
- 构件 4（动作）必须有**触发条件 + 执行步骤 + 审计点**三要素。

## 静态层 vs 动态层

| 层 | 构件 | 性质 | 维护频率 |
|---|---|---|---|
| 静态层 | 1 实体 + 2 关系 | 数据层（存什么 + 怎么连） | 高（每天可能新增实体） |
| 动态层 | 3 逻辑规则 + 4 动作 | 行为层（怎么约束 + 怎么流转） | 低（规则和动作相对稳定） |

## 质量门（Curated）

四构件方法论配套一个质量门机制——所有新实体先进 `inbox/`，过质量四维度审核后才进正式区：

| 维度 | 含义 | 判据 |
|---|---|---|
| **confidence** | 抽取可靠度（L1 规则=high / L3 别名=medium / L4 LLM 语义=low） | 不臆造 |
| **source** | 数据来源（哪个 spec / 哪个工具 / 哪份报告） | 可追溯 |
| **quality_score** | 完整度评分（0-100） | ≥ 60 才晋级 |
| **approved** | 是否人工审核通过 | false → true 才进正式区 |

> 不直接灌入是知识图谱健康的第一道防线。

## 跨领域实例

这套方法论正在被投研子区实例化，但它是**领域无关**的——给任何新领域建图谱可直接复用：

| 领域 | 实体类型示例 | 关系示例 | 规则示例 | 动作示例 |
|---|---|---|---|---|
| **投研**（已实例化） | stock / industry / strategy | belongs_to / matches / affects | 战法天气映射 / 报告图谱关联 | promote-from-inbox / sync-from-source |
| **智驾**（待建） | scenario / sensor / model | feeds_into / overrides / degrades | sensor 降级规则 / corner case 触发 | promote-corner-case-to-test |
| **读书**（待建） | book / concept / author | authored_by / cited_by / extends | 主题归类规则 | promote-note-to-concept |
