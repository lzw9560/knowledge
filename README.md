# 我的知识图谱

全维度个人知识体系，覆盖投研、技术学习、读书、项目追踪等领域。

## 结构
- `domains/investing/` — 投研知识图谱（股票/行业/研报/战法等 11 类实体）
- `domains-tech/` — 技术学习（占位）
- `domains-reading/` — 读书/学习（占位）
- `domains-projects/` — 项目/行业追踪（占位）
- `🏠 首页.md` — 全局 MOC 入口

## 使用
1. 用 Obsidian 打开本仓库根目录作为 vault
2. 必装插件：Dataview、Templater
3. 推荐插件：Smart Connections、Copilot for Obsidian、Graph Analysis
4. 详见 `domains/investing/README.md` 投研子区使用引导
