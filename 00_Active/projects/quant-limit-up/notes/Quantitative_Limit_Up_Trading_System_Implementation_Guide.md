# 量化打板助手系统实现文档 (PRD)

本规范旨在将短线打板（涨停板）交易中的筹码博弈、市场情绪及席位结构转化为可量化的计算机程序逻辑，配合东方财富终端进行盘前策略选股与盘中自动化/半自动化拦截，以获取次日的高溢价收益。

---

## 一、 系统全景架构设计

整个自研打板助手系统由四个核心模块组成，形成“数据->清洗->指挥->执行”的完整闭环。

1. **数据接入层**：盘后利用开源 `AkShare` 接口或东方财富公开行情数据，抓取全市场快照、涨停个股池及龙虎榜详情。
2. **计算引擎层**：运行盘前量化策略脚本，对筹码结构、日K线形态、席位分布进行穿透，精确计算出次日盯盘的关键死参数。
3. **最高指挥官（情绪控制）**：通过统计全市场亏钱与赚钱效应，决定今日大盘所处周期，输出硬性仓位管控命令。
4. **终端执行层**：将盘前生成的“操盘手册”核心因子，转化为东方财富软件的“智能价格条件单”和“集合竞价监控线”，进行精准狙击。

## 二、 核心战法量化策略与盘前因子

### 1. 弱转强接力战法（分歧转一致）
* **底层逻辑**：前一日多空博弈极其惨烈，封板极为艰难。次日由于主力资金在竞价阶段强势抢筹（超预期高开），导致看空资金反转看多，筹码迅速锁定，容易吸引全市场跟风资金，实现缩量加速晋级。
* **盘前量化筛选因子**：
  * `limit_up_days` >= 1（昨日必须是成功涨停板）。
  * `broken_duration_min` >= 20（昨日盘中多次炸板，且累计炸板时间大于或等于 20 分钟）。
  * `max_drop_pct` >= 5%（昨日炸板后，分时线最低点距离涨停价的回撤幅度 >= 5%，排除微幅震荡）。
  * `last_lock_time` >= 14:40:00（收盘前半小时内才勉强封死，属于偷袭板或极弱防守板）。
  * `vol_ratio_1d` 在 [1.8, 3.0] 之间（昨日换手率是前日的 1.8 到 3.0 倍。小于 1.8 换手不充分，大于 3.0 筹码失控爆天量）。

### 2. 形态反包战法（长上影洗盘修复）
* **底层逻辑**：个股前一日冲击涨停失败，留下极长上影线或大阴线。传统技术派判定为见顶，实则是主力借势暴力洗盘。次日若放量强行吞没昨日上影线顶点，则套劳盘全部化为轿夫，具备极强的视觉冲击力和溢价空间。
* **盘前量化筛选因子**：
  * `close_pct` < 9.5%（昨日未能封住涨停）。
  * `max_high_pct` >= 7.0%（昨日盘中最高涨幅突破过 7%）。
  * `shadow_length_pct` >= 4.0%（上影线长度 = 最高价 / 收盘价 - 1 >= 4%）。
  * `volume_1d` > `volume_2d` * 1.2（昨日成交量显著放量，必须是前一日的 1.2 倍以上）。
  * `ma_5_status` == "Upward"（5日、10日均线多头排列向上发散，拒绝下行通道的超跌反弹）。

## 三、 龙虎榜席位过滤器（筹码安全员）

即使形态和逻辑再好，一旦筹码结构被恶性资金控盘，次日极易遭遇无情核按钮。盘前必须穿透前一日龙虎榜详情（`ak.stock_lhb_detail_em`）：

1. **恶性席位黑名单（硬性剔除）**：
   * **黑名单库**：包含“中国国际金融上海分公司”、“中金财富”、“招商证券深圳招商证券大厦”、“华泰证券总部”、“中信证券总部”等量化基金及知名一日游席位。
   * **风控指标**：买入前五席位中一旦出现不少于 1 个黑名单席位，且买入金额占比超过前五买入总额的 15%，**看板直接标记【拒绝介入】**。
2. **独食独大结构（风险提示）**：
   * **风控指标**：买一席位买入金额占前五总买入额的 55% 以上，或占全天成交额的 10% 以上。缺乏资金合力，一旦该席位次日砸盘，承接力极易崩溃。
3. **散户大本营霸榜（筹码涣散度）**：
   * **风控指标**：买入前五席位中，包含 3 个及以上东方财富证券“拉萨团结路”、“拉萨东环路”等席位。说明人气过热，筹码极度涣散，主力游资已借光环离场。

## 四、 大盘情绪熔断机制（最高指挥官）

系统设立最高指挥官机制，通过量化前一交易日短线的赚钱/亏钱效应，直接输出今日最高操盘仓位。

### 1. 核心情绪监控因子
* **大面股家数 (`big_loss_count`)**：昨日全市场“当天最高点跌到收盘价，跌幅 >= 10%”的个股天数。它是监测高位追高打板亏钱效应最灵敏的熔断指标。
* **跌停家数 (`floor_count`)**：昨日收盘非 ST 跌停的个股总数，用来监测全市场恐慌踩踏深度。
* **连板晋级率 (`ladder_success_rate`)**：昨日连板成功晋级下一梯队的个股数量 / 昨日所有连板股基数。
* **连板最高高度 (`max_ladder_height`)**：全市场空间板的最高天数，侦测情绪天花板。

### 2. 状态机决策与动态仓位规范
* **绿色主升浪周期**（大面股 <= 3家 且 跌停股 <= 5家）：资金接力意愿极强，强者恒强。建议仓位：**70% ~ 100%**。全面开启【弱转强】竞价单和【形态反包】智能触价条件单，单笔委托金额设为标准额度。
* **黄色震荡分歧期**（4 <= 大面股 < 8 或 5 < 跌停股 < 20）：出现局部亏钱效应，连板晋级率下降。建议仓位：**30% ~ 50%**。严格执行龙虎榜席位过滤。东财单笔委托金额直接砍半，只保留主线核心股条件单，剔除杂毛。
* **红色全面退潮期**（大面股 >= 8家 或 跌停股 >= 20）：亏钱效应爆炸，极易遭遇天地板踩踏。建议仓位：**0% ~ 20%（强制熔断）**。手动关闭东方财富的所有智能条件单。当天不盲信任何脉冲拉升，严禁开盘冲动打板，强制锁仓防守。

## 五、 东方财富终端盘中实操指南

### 1. 弱转强接力盘中动作（09:15 - 09:35）
* **09:15 - 09:20**：看主力底牌。若竞价大单（>5000手）顶在 +7% 以上，属于主力表态。
* **09:24:30 算量校验**：核对东财定格的竞价成交额。
  * **硬性阀值**：1进2个股竞价成交额 >= 1500万元；2进3及以上个股 >= 3000万元（或精准匹配脚本算出的昨日全天成交额的 10%）。
  * **配合价格**：开盘价最终沉淀在 **+2% ~ +5%** 之间。低于 +2% 转强失败，高于 +7% 容易消耗多头空间。
* **买入切入点**：09:30:03 开盘分时线下探不破零轴（昨日收盘价），随后伴随东财 L2 逐笔成交出现密集红字大单（每笔 >= 2000手）疯狂刷屏。使用东财**闪电交易机制，以 +8% 价格市价扫盘**切入。

### 2. 形态反包智能条件单拦截（09:30 - 15:00）
* **步骤一：配置触价单**
  * 在东财电脑端/手机端点击“交易” -> “智能条件单” -> “价格条件单”。
  * 触发条件设为：`股价 >= [昨日K线最高价 + 0.01元]`。委托方式选择“市价委托”。
* **步骤二：触发后5秒“人工三看”校验**
  * **一看 L2 逐笔成交组合**：突破最高点那一瞬间，必须是连续不间断的红色大单（如1500手、3000手连发），拒绝由几百手散户单凑上去的无量诱多。
  * **二看量比换手**：盘中量比 >= 3.5，且实时换手率已达到昨日全天的 60% 左右，证明量能充足，有能力解放昨日套牢盘。
  * **三看买卖队列**：东财 L2 挡位中，买二至买五挂有持续的万手锁仓大单推高股价，且卖五或涨停板上没有无法撼动的巨额压单（盖帽）。
