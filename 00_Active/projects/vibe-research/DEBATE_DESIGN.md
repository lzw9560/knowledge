# 多空辩论设计

## 核心思想

开源的多 agent 金融框架（TradingAgents、ai-hedge-fund 等）流程末端都有一个 trader / portfolio_manager 出买卖结论。
**本项目刻意不做那一层。**

这里的多 agent 终点是**分歧**，不是结论。

## 辩论流程

```
① 事实底稿   后端按固定清单拉 13 项客观数据（不经 LLM）
              ↓  多空双方吵的是同一份数据
② 多方研究员  基于底稿立论：核心论点 + 支撑证据 + 前提条件
③ 空方研究员  基于底稿质疑：核心质疑 + 风险证据 + 前提条件
   （可选）    交叉反驳：逐条回应对方
④ 中立主持    双方共识 / 真正的分歧点 / 验证清单 / 数据缺口
```

## 刻意约束

- **底稿先行**：不让模型自己想起来调哪个工具，数据确定可复现
- **每条论点必须标数据来源**：无数据支撑的标注「无数据支撑」
- **中立主持不裁决谁对**：产出是「你接下来该去看什么」
- **走限流接口的数据串行抓取**：`em_get` 防封

## 一次辩论的开销

| | 一轮 | 两轮（加交叉反驳） |
|---|---|---|
| 模型调用 | **3 次** | **5 次** |
| 输入内容 | ~3.5 万字 | ~6 万字 |
| 产出 | ~4 千字 | ~7 千字 |
| 耗时 | **~100–120 秒** | ~3 分钟 |

## 反思审计

同一个思路的延伸：对一段已写好的分析做推理审计，挑出「听起来合理但没有依据」的部分。
开销：只有 **1 次模型调用**。

## 五维投研分析框架

让 AI 分析个股时，自动按以下五维组织结论：
1. **估值** — PE/PB/历史分位/前向PE/PEG
2. **资金面** — 主力资金流/两融/龙虎榜
3. **财报质量** — 营收/净利/ROE/毛利率
4. **行业景气** — 板块归属/行业强弱/概念
5. **事件催化与风险** — 公告/解禁/互动易

框架只规定「怎么读数据」、不规定买卖，方向仍由你自己的 AI 决定。
