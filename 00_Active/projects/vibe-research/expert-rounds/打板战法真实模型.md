# 打板战法真实模型（practitioner-grounded）

> 「游资打板操盘手」备料（2026-09-09）+ §44 harness 代码核实。**对照 §44 浅模型**：§44 测 selection D+1 path（涨停已成的次日续涨力），practitioner 确认 **edge 不在选股层**（与 §44 selection lift<1 一致）——edge 在**盘中情绪博弈的 conditional 层**。

## 真实 entry/exit/holding（vs §44 D+1 open）

- **Entry = 盘中封板瞬间扫板/排板**（非提前埋单、非 D+1 open），或炸板回封瞬间打，或竞价高开≥5%+放量时竞价介入。赵老哥手法：不堵单，跟风封上后加单造强势感（中毅达案）
- **Exit**：隔日超短——次日竞价/冲高卖，「不涨停就全出」；连板股持到断板日
- **Holding**：1-3 日，绝大多数 T+1；止损 -3%~-7% 无条件走

**§44 错配**：§44 entry=D+1 open（涨停已成次日），战法 entry=盘中封板瞬间。测的不是同一个 entry。

## edge 来源（盘中 conditional 因子，§44 5/10 没测）

- **封单成交比**（封单额/成交额）>3 强、<1 危险〔共识〕
- **封单诚意**（增/减/撤/砸开，震荡市封单忽大忽小=演戏）〔共识〕← 需 L2 tick，§44 未接线
- **竞价量能**（≥昨日 3% 或首板爆量一半）〔共识〕
- **情绪周期阶段**（发酵期胜率最高）〔淘股吧共识〕
- **龙头辨识度+板块梯队完整**〔共识〕
- 龙虎榜席位溢价（赵老哥/陈小群等）〔个人经验，2025 已减弱〕

## conditional edge 窗口（§44 池化稀释成无）

**Work 条件（极窄）**：情绪发酵期 + 题材催化 + 板块龙一 + 封单强不撤 + 换手上扬 + 10:30 前封板 + 梯队完整 + 低价小盘(<10元)
**Fail 条件**：退潮期 + 无题材/炒冷饭 + 封单弱/假封单 + 尾盘偷袭板 + 缩量一字独食 + 炸板

→ edge 高度 regime-dependent（发酵期炸板率<30%胜率最高，退潮期禁打）。**§44 全样本池化无分层**，把 conditional edge 稀释成 lift~1，是 confounder 假象风险（late_lock 偏小盘→小盘次日反转→lift<1）。

## 诚实 caveat（tempers「战法有效」）

- **edge 薄**：陈小群（top 游资）325 日 3416 次打板，首板成功率仅 50%，封板成本 102%-103%，次日 98% 抛，**净收益仅 1.96%**〔百家号数据未独立核实〕
- **survivorship 质疑**：雪球算 ~1 亿人参与打板仅 ~100 人成功=百万分之一，可能随机运气非技术〔逻辑有力未严验〕。只看连板成功股=严重选择偏差，须建失败样本库（炸板/退市/ST）
- **2025 量化 3.0 decay（最致命）**：2025-07 量化新规（高频≥300笔/秒、撤单费 0.5元/笔、禁融券 T+0）；连板次日溢价消失甚至负溢价，2024 年 73% 涨停板遭量化融券砸盘次日低开 5.2%；**量化 3.0 占涨停板 80% 取代游资成主角**；打板成功率不足 50%（2025 年 44%）；游资转趋势股不登龙虎榜避曝光。**edge 正从「打板接力溢价」迁移到「趋势波段+政策确定性」**

## verdict：打板战法真实模型

- edge **不在 T-1 selection**（§44 测对了一半——selection 层无 edge，practitioner 共识一致）
- edge **在盘中 conditional 情绪博弈**（封单诚意/竞价量能/情绪周期/龙头/梯队），**极窄条件窗口下成立**
- 但 **薄**（陈小群 50%/1.96%）+ **survivorship 可疑** + **2025 量化 3.0 后 decayed 近消失**
- §44 的 no-edge 是「测错层（selection 非 盘中）+ 池化稀释 conditional」的假象，不是「战法无 edge」——但战法 edge 本身也 thin + decayed

## 要验真须

- 测**盘中 conditional 层**（非 selection D+1 path）
- 建**L2 封单诚意 + 竞价量能 + 情绪周期 + 题材**数据（§44 5/10 缺的，#3 数据基建前提）
- 按**情绪周期 regime 分层**（发酵期 vs 退潮期），非池化
- 建**失败样本库**（炸板/冲板失败对照），解 survivorship
- 诚实面对 **2025 decay**：edge 可能已死，pre-2025 经验不适用
