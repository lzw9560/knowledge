# 打板量化模型设计（4 专家 workflow + 综合）

> 「打板设计 workflow」（wxyn7gdgy，4 专家：微结构/量化建模/数据基建/游资 validate + 综合）产出。edge 在**盘中 conditional 层**（非 selection，§44 测错层已证）。6 草考因子 + conditioning + 数据 map + codebase 复用 + validate 路径。

## 6 草考因子（量化定义 + 数据源 + feasibility）

1. **封单成交比 seal_turnover_ratio** = seal_amount/turnover_amount（>3 强、<1 危险）。数据：东财 zt_pool `fund`（封单额）+ tencent `amount_wan`（成交额），已在 `seal_intraday_snapshots`(60s) 采集。需联读算 ratio（10 行纯函数）。涨停后才有 seal_amount。
2. **封单诚意 seal_sincerity**（5 维向量，不丢信息）：seal_slope（回归斜率，正=增强）/seal_delta_ratio（净增减比）/seal_volatility（高=演戏忽大忽小）/break_count（seal→0 跳变）/seal_drawdown（峰值回撤）。3 已有（`compute_trajectory`）+3 需补（各 10 行）。诚意强=slope>0∧delta>0∧volatility<0.2∧break=0∧drawdown<0.1。**60s 粒度是免费源上界，L2 逐笔（撤单方向）需付费不可能免费得**。
3. **OFI 订单流失衡** = Σ[Δbuy_i_vol − Δsell_i_vol]（5 档，涨停前）；涨停后退化为 Δseal_amount（封单净增=买压）。数据：`bids(code)`（eastmoney.py:653，已接线五档）。需建 3-5s 轮询采集器 + OFI 纯函数（20 行）。em_get 0.3s 限流，单股 3s 可行多股分批。
4. **竞价量能 auction_vol_ratio** = auction_amount/prev_total_amount（≥3% 强）。数据：`intraday_auction_snapshots`（hithink 9:15-9:25 live+final，已采集）。需联读 prev_total_amount。**§44 reframe 标记的最未证否盘中 edge**（封板时间/秒板已证否，竞价量比未证否）。
5. **封板时间 seal_time**：first_seal_time（首封，已有）+ last_lock_time（末封，`compute_derived_features` 已有）。⚠️ **定义敏感致命**：late_lock first_plate_h2 版 lift 1.33 p=0.012（信号）vs zt_pool 版 lift 0.62（反信号）——下注前必须锁 first_plate_h2 版精确定义。
6. **盘口买压比 bid_ask_pressure** = Σbuy_vol/Σsell_vol（5 档，>3 强）。`first_board_confirm.py:359` 第⑤维当前人工标注占位 → bids() 改 10 行自动算。涨停时 sell=0 ratio→∞，需 cap 或转 seal_amount。

## conditioning + 测试（§44v2 框架，非池化）

- **情绪周期 regime 分层**（发酵期/退潮期，sentiment_weather 炸板率/连板高度代理）→ 分层内算 lift 非全样本池化
- **day-clustered + 市值/板块分层**（防 late_lock 偏小盘→小盘次日反转→lift<1 confounder）
- **每因子对窗口+n 够才上重方法论**（≥200 picks 或 ≥60 天；当前 seal_intraday 自 2026-08-11 起 ~30 天 underpowered，标「探索性」不出「劣于随机」）
- **失败样本对照**：建炸板/冲板失败库（open_count>0 作负样本），解 survivorship（当前 universe 全已涨停池无对照）
- **Bonferroni 按 n 调**不过度纠正

## 数据 map

- **免费可得（已接线/可建）**：五档 bids、封单 seal_amount(60s)、竞价 trajectory(9:15-9:25)、量比/成交额、5min bars、盘口异动大笔买入
- **免费不可得（需付费）**：L2 逐笔成交、委托队列、十档、撤单明细（同花顺 OpenAPI/东财超级 Level-2/新浪/券商接口均付费）。akshare/mootdx/tencent 无 L2 tick
- **频率**：OFI ≥3s 五档轮询（em_get 0.3s 限流多股分批）、封单诚意 60s 上界（zt_pool 端点限流≥10min R6 约束不可加密）、竞价 9:15-9:25 每 1min

## 实战 validate 路径

1. 等 live 累积 60 天（intraday_accumulation_store S167 已在跑）→ §44v2 复测 6 因子分层 lift
2. 失败样本库（炸板/冲板失败 open_count>0）作负样本对照，解 survivorship
3. **诚实面对 2025 decay**：量化占涨停 80%、连板次日溢价消失、打板成功率 44% → pre-2025 经验可能已不适用，复测若 lift<1 须接受「edge 已死」而非继续找窗口
4. 陈小群基准：50% 成功率/1.96% 净收益/102-103% 成本 → 任何验证须对标这个薄 edge 基准，扣成本后净正才算 edge
5. late_lock 定义先锁（first_plate_h2 版 p=0.012 是唯一接近 gate 的信号，但定义敏感到两版反结论）

## verdict

- 打板 edge 在**盘中 conditional**（6 因子：封单成交比/诚意/OFI/竞价量能/封板时间/盘口买压），§44 selection 测错层已证否一致
- codebase 已有大半基建（bids/intraday_features/intraday_accumulation_store/first_board_filter），新建限于五档轮询+OFI+conditioning harness
- **L2 逐笔免费不可得**→60s/3s 粒度是上界，封单诚意撤单方向精度需付费（标 coarse 近似）
- 等 60 天 live + 失败样本库 + 诚实面对 2025 decay，才能定打板 edge 死活
- 综合 synthesis 统一文档（priority 排序+与趋势波段对照+诚实标注）在 workflow output file，需要时提取
