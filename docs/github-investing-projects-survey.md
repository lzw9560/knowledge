3. **流水线设计**：qlib 的完整研究流水线（数据 → 特征 → 模型 → 回测 → 优化）可作为我们系统架构的参考蓝图

### 6.2 模型层面

1. **多 Agent 协作**：TradingAgents 的辩论式决策框架是核心差异化能力，建议持续深耕
2. **金融 NLP**：finBERT 证明了领域微调的重要性，建议在我们的情感分析模块中引入类似方法
3. **组合优化**：PyPortfolioOpt 提供了成熟的优化工具，可作为我们组合管理模块的基础

### 6.3 工程实践

1. **MCP 工具化**：a-stock 的 MCP 工具化思路值得借鉴，可将我们的分析能力封装为标准化工具

3. **文档优先**：qlib/vnpy 的成功离不开完善的文档，建议加强技术文档建设
